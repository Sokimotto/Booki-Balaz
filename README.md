# Booki Balaz

A lightweight, English-language, offline-ready brick breaker PWA for desktop and mobile.

## Controls
- Mouse/touch: move paddle and launch ball
- Left/Right arrows or A/D: move paddle
- Space/Up arrow: launch ball
- P: pause

## Publish
1. Upload the **contents** of this folder to a GitHub repository.
2. GitHub: Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Open your GitHub Pages HTTPS URL and test the game, including offline after first load.
4. In PWABuilder.com, submit your GitHub Pages URL and select Windows packaging.
5. Download the Windows package and follow Microsoft Partner Center's current Store submission instructions.

No payments, ads, analytics, or user accounts are included. Game progress is session-only.
